# 03 · E2E tests with Playwright

|                     |                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------- |
| **Goal**            | Test the real SSR Worker end to end, including streaming and failure modes, with no LLM key |
| **Time box**        | 12 minutes (30–42)                                                                          |
| **Starting branch** | `step-2-unit-tests` (solution: `step-3-e2e`)                                                |

```bash
git checkout step-2-unit-tests
pnpm exec playwright install chromium
```

## Why against `wrangler dev`?

`ng serve` runs the server code in Node. Production runs it in a Cloudflare Worker. Playwright starts the **built** app in `wrangler dev`, the same `workerd` runtime used in production, so SSR-only bugs show up in tests. The `localStorage` bug from module 01 is one example. Adding `--var SMARTCART_PROVIDER:mock` forces the deterministic mock assistant, so the tests never need a Gemini key and never call a real LLM.

## Steps

1. **Config** ([prompt 3.1](prompts.md#31-playwrightconfigts)). Create `playwright.config.ts` with:
   - `testDir: 'e2e'`, Chromium only, and `baseURL: 'http://localhost:8787'`.
   - `webServer.command: 'pnpm wrangler dev --port 8787 --var SMARTCART_PROVIDER:mock'`, with `reuseExistingServer: !process.env.CI`.
   - `forbidOnly` and `retries: 2` on CI, `trace: 'on-first-retry'`, and the `list` and `html` reporters.
   - No new tsconfig. `e2e/tsconfig.json` is already in the repo, and `pnpm typecheck` picks up your specs and `playwright.config.ts` automatically.

   `pnpm e2e` runs `pnpm build && playwright test`, so the server always serves a fresh `dist/`.

2. **Hydration helper and shop spec** ([prompt 3.2](prompts.md#32-hydration-helper-and-shop-spec)).
   - **Wait for hydration.** Server-rendered HTML is visible before Angular attaches event listeners, so a click that comes too early does nothing. Angular removes the `ngh` attribute from each component as it hydrates, so this is a web-first wait with no fixed timeout:

     ```ts
     export async function gotoHydrated(page: Page, url: string): Promise<void> {
       await page.goto(url);
       await expect(page.locator('[ngh]')).toHaveCount(0);
     }
     ```

   - Cover the catalog, search, add to cart → cart page, and **product detail SSR**. For SSR, use `page.request.get('/product/…')` and assert on the raw HTML, so no JavaScript has run.

3. **Assistant spec** ([prompt 3.3](prompts.md#33-assistant-spec-streaming-and-failures)). The mock provider covers the happy paths: "show me headphones under $100" and "add the cheapest mug to my cart". Use `page.route` to simulate failures:

   ```ts
   // HTTP 500
   await page.route('**/api/chat', (route) => route.fulfill({ status: 500, body: 'boom' }));

   // An error partway through the SSE stream
   const sse = (...events: object[]) =>
     events.map((e) => `data: ${JSON.stringify(e)}\n\n`).join('');
   await page.route('**/api/chat', (route) =>
     route.fulfill({
       contentType: 'text/event-stream',
       body: sse(
         { type: 'text', delta: 'Partial answer' },
         { type: 'error', message: 'Stream interrupted' },
         { type: 'done' },
       ),
     }),
   );
   ```

   **Streaming state.** Delay the routed response, then assert that `assistant-send` is disabled and `typing-indicator` is visible. Once the reply arrives, assert that send is enabled again.

4. **Run them:**

   ```bash
   pnpm e2e                           # build, start wrangler dev on :8787, run the tests
   pnpm exec playwright test --ui     # UI mode: time-travel through each step
   pnpm exec playwright show-report   # open the last HTML report
   ```

   UI mode and `playwright test` don't rebuild. Run `pnpm build` first if you changed app code.

## Patterns to insist on

- Locators: `getByTestId` (the app has `data-testid` everywhere) or `getByRole`. Avoid CSS chains.
- Web-first assertions (`await expect(locator).toHaveText(…)`). Never use `waitForTimeout`.
- Mock provider only. No real Gemini calls in CI.

## Expected result

`pnpm e2e` passes 9 tests: 4 shop and 5 assistant.

## If stuck

- **Port 8787 in use.** Another `wrangler dev` or `pnpm preview` is running. Stop it, or find it with `lsof -i :8787`. Locally, Playwright reuses an existing server, so a stale one can serve an old build.
- **"Executable doesn't exist".** Run `pnpm exec playwright install chromium`. On Linux CI, use `--with-deps`.
- **Clicks do nothing.** You didn't wait for hydration. Use `gotoHydrated`.
- **Take the solution:**

  ```bash
  git checkout origin/step-3-e2e -- playwright.config.ts e2e
  ```

  Or check out the whole branch: `git checkout step-3-e2e`.
